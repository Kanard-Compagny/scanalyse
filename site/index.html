Trouver où ça coince, entre le code, la douchette et l'imprimante.

Scanalyse lit les codes-barres de vos clients, compare ce que leur douchette transmet vraiment et explique les programmes de leurs imprimantes d'étiquettes. Gratuit, sans installation, toutes marques.

Trois appels qu'on connaît par cœur

« La douchette ne lit pas. »

Le code est lu sur une photo ou une capture : contenu, clé de contrôle, contraste, zone blanche. On sait tout de suite si le code est en cause.

« Le logiciel reçoit n'importe quoi. »

On scanne avec la douchette du client : Scanalyse compare ce qu'elle envoie au vrai contenu, octet par octet, et donne le code de configuration qui corrige.

« L'étiquette sort mal. »

Le programme ou le fichier de configuration de l'imprimante est lu ligne par ligne, avec l'aperçu de l'étiquette et chaque erreur expliquée.

Ce qu'il y a dedans

Analyser une image
Photo, capture d'écran ou PDF de plusieurs pages : chaque code lu, ses données GS1 décodées, ses défauts signalés.
Créer un code
Plus de 25 types : QR personnalisé, Data Matrix, GS1, EAN, Code 128, PDF417, MaxiCode. Export en image.
Étiquette imprimante
ZPL, TSPL, EPL2, DPL, SBPL, Fingerprint : aperçu, contenu des codes, modèles prêts à l'emploi, envoi à l'imprimante.
Conf imprimante
Fichiers de configuration analysés, convertis d'une marque à l'autre ou créés depuis un formulaire, Wi-Fi compris. L'imprimante est reconnue sur le réseau.
Banc d'essai douchette
Ce que la douchette transmet, comparé au code : clavier, préfixe, suffixe, séparateur GS1. Codes de configuration Honeywell, Datalogic, Zebra.
Appareils de lecture
Douchettes USB, série et HID POS, terminaux Android en USB ou en Wi-Fi. Un téléphone sans lecteur lit avec sa caméra.
Historique et rapports
Analyses rangées par dossier client, rapport PDF à votre en-tête, dossier partageable avec l'équipe.

Démarrer en deux minutes

  1. Téléchargez Scanalyse.exe et placez-le où vous voulez, même sur une clé USB.
  2. Lancez-le. Si Windows affiche « Windows a protégé votre ordinateur », choisissez « Informations complémentaires » puis « Exécuter quand même ».
  3. Choisissez la langue et vos dossiers, puis suivez la visite guidée.
