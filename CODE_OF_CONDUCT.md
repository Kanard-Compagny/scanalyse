# Code de conduite · Code of conduct

🇫🇷 Scanalyse est un projet d'entraide entre techniciens. Dans les tickets, discussions et contributions :
- on reste **courtois et bienveillant**, quel que soit le niveau de chacun ;
- on critique les idées et le code, **jamais les personnes** ;
- pas d'insultes, de harcèlement, de propos discriminants ni de publicité ;
- on ne publie **aucune donnée client** (étiquettes réelles, adresses, mots de passe Wi-Fi) : anonymisez vos exemples.

Les messages qui ne respectent pas ces règles peuvent être modifiés ou supprimés, et leurs auteurs exclus du projet. Pour signaler un comportement, contactez le mainteneur via son profil GitHub.

🇬🇧 Scanalyse is a project of technicians helping each other. In issues, discussions and contributions:
- stay **polite and kind**, whatever everyone's level;
- criticize ideas and code, **never people**;
- no insults, harassment, discriminatory remarks or advertising;
- never publish **customer data** (real labels, addresses, Wi-Fi passwords): anonymize your examples.

Messages that break these rules may be edited or removed, and their authors excluded from the project. To report a behavior, contact the maintainer through their GitHub profile.
